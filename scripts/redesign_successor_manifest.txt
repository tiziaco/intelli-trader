# Successor manifest for the venue/account redesign must-have gate.
#
# Every file that replaces, absorbs or renames one of the 27 baseline files, plus every
# module the redesign introduces. Measured against the frozen baseline (3,886 code lines)
# by:
#
#   poetry run python scripts/measure_redesign_baseline.py \
#       --manifest scripts/redesign_successor_manifest.txt
#
# Kept in sync AS THE STAGES LAND rather than authored at the end, so the sign of the
# must-have is observable throughout: a stage that trends it positive is a stop-and-report
# event, and that is only detectable if the manifest is current. Entries are added when a
# module appears and removed when one is deleted.
#
# Stage 1: the backtest root moved (paths updated in place); trading_system/live/ appeared.
# Stage 2: venues/catalog.py + connectors/pool.py appeared (their predecessors —
#          registry.py, provider.py, the plugin modules — die in Stage 7, so both sides are
#          counted for now and the delta is expected to be positive until then).
# Stage 3: account/venue.py DELETED — venue truth is now AccountSnapshot, read by the
#          execution adapter. (An earlier note here claimed exchanges/base.py was already
#          inside the measured set; it was not. It is now — see the recipe-host correction.)
# Stage 4: venues/accounts.py appeared and ABSORBED four modules — venue_account_manager.py,
#          assemble.py, lifecycle.py and venue_uid_guard.py are DELETED.
# Stage 5: feed_binder.py DELETED — the data adapter owns its own session, so there is no
#          borrowed connection to bind. Its successor, build_okx_data_provider, lands in
#          price_handler/providers/okx_provider.py: a RECIPE HOST, now counted (below).
#
# THE RECIPE-HOST CORRECTION (settled after Stage 5). Several recipes landed in host files
# that predate the redesign while the modules they replaced were among the baseline 27, so
# their lines were counted leaving and not counted arriving. Measured: those hosts grew
# 1,182 -> 1,334 code lines across Stages 3-5 while this manifest appeared to fall
# 3,886 -> 3,852. The gate's comparand is therefore the EXTENDED baseline
# (measure_redesign_baseline.EXTENDED_BASELINE_TOTALS = 31 / 11,684 / 5,068 at 3a2c7692),
# and this set must list the hosts or the script refuses to report a delta.
# Like-for-like at Stage 5: 5,186 code -> +118, NOT -34.
